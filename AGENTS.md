# AGENTS.md - DeepSeek playbook

## 1. Project map
- Single module `:app`, package `com.shibi.musicplayer` (minSdk 26, targetSdk 36). Kotlin + Jetpack Compose (Material 3) + Media3.
- `MainActivity.kt`: entry point, `setContent { MusicPlayerTheme { MusicApp() } }`.
- `domain/`: pure Kotlin logic (`PlaybackQueue`, `PlaybackTime`, `Track`, `AudioOutputs`, `OutputRoute`, `NavWheelMath`, `PlaylistOrder`, `Video`, `VideoFormat`, `VideoAccess`, `PlaybackArbiter` with `VideoFocusPolicy` and `InlineVideoBox`), unit-tested. Android stays out of these types.
- `library/`: `MusicRepository` (MediaStore) and `LibraryViewModel`; video side (V2; listed by the V3 Videos section): `VideoRepository` (MediaStore.Video + `ContentObserver` flow), `VideoLibraryViewModel` (created only by the Videos section), `VideoThumbnailFetcher` (Coil 3, attached per request via `videoThumbnailRequest`).
- `playlist/`: Room playlists (`PlaylistDatabase`, `PlaylistDao`, `PlaylistRepository`, `PlaylistViewModel`). Schema version 4, database name `playlists.db`. `favorites` is the per-song row: `favorite`, `likedAt`, and `playCount` (version 4, `MIGRATION_3_4`).
- `video/` (V4): `VideoEngine` interface + pure `VideoStateReducer`, `VlcVideoEngine` (the only file that names `org.videolan`; LibVLC created lazily; `content://` opened as a `ParcelFileDescriptor` and passed as `Media(libVlc, fd)`), `VideoAudioFocus` (media3 `AudioManagerCompat`, noisy receiver), `VideoViewModel` (activity-scoped in `MusicApp`, owns the engine, no engine until the first `open`). Tests use `FakeVideoEngine`.
- `playback/`: `PlaybackService` (MediaSessionService), `PlayerViewModel`, `PlayerUiState`, `TrackMediaItems`, `OutputCommands`.
- `ui/`: `MusicApp` (navigation, routes in `SectionRoutes`), `SectionScaffold` (list viewport plus a non-overlapping chrome slot for the mini player and carousel), `LibraryScreen` (`NowPlayingBar`), `PlaylistsScreen`, `PlaylistDetailScreen`, `AddToPlaylistSheet`, `NavCarousel` (3D ring, `CarouselMath`), `BrowseScreens` (Favorites, Recent, Search, Settings), `VideosScreen` (`videos` route, `VideoRow`, stateless `VideosContent`, inline player column when a video is open), `InlineVideoPlayer` (compact box, `VideoSurface` `AndroidView`, white controls on a fixed black `ContrastSurface`), `VideoPermission` (lazy video permission request, partial banner, denied prompt), `PlayerScreen`, `AlbumArtwork`, `AudioPermission`, `OutputPickerSheet` (audio output picker), `PlaybackRoute` (live `AudioDeviceCallback`), `theme/Theme.kt`.
- Tests: `app/src/test/java/com/shibi/musicplayer/` (plain JUnit 4). Room DAO tests and Roborazzi screenshots use Robolectric. Screenshot PNGs are recorded to `app/build/outputs/roborazzi/` by `recordRoborazziDebug` (plain `test` does not write them).
- Libraries (gradle/libs.versions.toml): AGP 9.4.0, Kotlin 2.4.10, core-ktx 1.18.0, activity-compose 1.13.0, lifecycle 2.10.0, Compose BOM 2026.06.01, navigation 2.9.8, media3 1.11.1, coil 3.5.0, coroutines 1.11.0, room 2.8.5, ksp 2.3.12, junit 4.13.2, libvlc-all 3.7.7 (not used in code yet; ABI splits arm64-v8a + x86_64, compressed jniLibs, `libvlc_version` string generated by `resValue`). `LicensesScreen` (`settings/licenses`) shows LGPL-2.1 (`res/raw/lgpl_2_1.txt`) and OFL-1.1 (`res/raw/ofl_1_1.txt`); `scripts/check_16kb_alignment.py` reports native-lib 16 KB alignment in CI.
- Style: 4-space indent, trailing commas, one composable per concern, private helper composables, user-facing text in `res/values/strings.xml` via `stringResource`, dependencies only through the version catalog (`libs.*`).

## 2. Definition of done
- Run `gradlew.bat assembleDebug test` locally (JDK 17 and Android SDK are installed; if JAVA_HOME/ANDROID_HOME are missing in your shell, load them from the user environment). It must be green before you say you are done. Report the actual result.
- No new compiler warnings.
- Only the files named in the ticket are touched.
- Logic changes come with new or updated unit tests.

## 3. Ticket format
Every task arrives as: **Goal**, **Files to touch**, **Acceptance criteria**. Do exactly that; ask nothing, invent nothing extra.

## 4. Test-first
For logic changes, write or update the failing unit test first, then the code. Keep Android framework calls out of pure logic so it stays JUnit-testable.

## 6. Lessons learned
- androidx.mediarouter's `MediaRouteChooserDialog` extends `androidx.appcompat.app.AppCompatDialog`, and mediarouter does not expose appcompat at compile time. Using mediarouter dialog classes requires `implementation(libs.androidx.appcompat)` in app/build.gradle.kts (catalog alias `androidx-appcompat`).
- You cannot read the Gradle cache (~/.gradle/caches): OpenCode denies external directories and the run aborts. Do not try. Verify an API by compiling (gradlew.bat assembleDebug) instead.
- `android.media.AudioDeviceCallback` is a top-level class (not nested in AudioManager). `AudioManager.AudioRecordingCallback` IS nested.
- Only the repo directory is readable/writable for you. Never write or read files in %TEMP% or other outside paths; pipe Gradle output to the console or to build/.
- Scaffold applies insets only to its content padding. Custom composables in bottomBar/topBar must handle navigation/status bar insets themselves (navigationBarsPadding()).
- `awaitEachGesture` cannot call `Animatable` suspend functions. Launch them on `rememberCoroutineScope`.
- Room 2.8: `implementation(libs.androidx.room.runtime)` and `ksp(libs.androidx.room.compiler)`. Do not add `room-ktx`. KSP plugin: `com.google.devtools.ksp` version `2.3.12`.
- `NavHost` destination `route` is the pattern string (`playlist/{playlistId}`), not the filled path.
- A decorative stroke on `#0E0E12` needs about 40% white to reach ~3:1. White at 14% disappears.
- Noto Sans Tamil has no U+2026. `TextOverflow.Ellipsis` on that family draws the mark twice. Keep the original characters and paint Tamil as a Noto span inside a Jakarta paragraph so one Jakarta ellipsis is drawn. Do not slice the string.
- Carousel v2: icons ride the ring on faint glass beads; a fixed opaque glass lens (pill) sits at the front and each icon crossfades/grows into the lens tint as it passes (`frontness`). Per-frame values are read only in `Layout` placement (`placeWithLayer`), layer and draw lambdas; `selectedIndex` is `derivedStateOf`. Motion is M3 Expressive: ring `spring(0.8, 380)` carrying the release velocity to `flingTarget` (0.22 s projection, max one turn, one spring, no decay-then-snap), lens press `spring(1.0, 3800)`, lens settle `spring(0.6, 800)`. `SegmentFrequentTick` per detent while the user drives it, `SegmentTick` on settle. Animator scale 0 = reduce motion: snap, no momentum, no blur. Labels hand off (`labelAlpha` is 0 at the half step). The older tile notes below describe v1 geometry, which is unchanged (radius, scale, alpha, tilt, lift).
- The bottom nav is a 3D carousel of glass tiles (`CarouselMath` + `NavCarousel`), not a stroked arc. Eight sections, 45° apart, radius `0.44 * width`. Tiles are 44–60dp, independent of the ring so a wider orbit does not grow them. At rest the front, ±45°, and ±90° are visible and symmetric; the back is hidden (`cos θ < -0.1`). Scale, alpha, `rotationY`, and the upward Y offset all come from `cos θ`. Apply scale and `rotationY` on one `graphicsLayer` (`cameraDistance` `12 * density`). Shade the plate only.
